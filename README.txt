# Weekly Hours — installable Android app

## Publish it free with GitHub Pages
1. Sign in to GitHub (create a free account if needed).
2. Create a new **public** repository named `weekly-hours`.
3. Upload the files in this folder (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then Save.
7. Wait a minute or two. GitHub will show your website address, usually:
   `https://YOUR-USERNAME.github.io/weekly-hours/`
8. Open that address in Chrome on your Pixel 10 Pro.
9. Tap Chrome's **⋮** menu → **Install app** (or **Add to Home screen**) → Install.

## Notes
- Hosting and installation are free.
- Your work entries and preferences are stored in this browser on this phone using local storage. They are not automatically synced to another device.
- Avoid clearing Chrome's site data if you want to keep saved entries. Consider copying your weekly summary regularly.
- The app shell is cached for offline launch after the first successful visit. Tailwind styling and Google Fonts are loaded from their CDNs and may need an initial online visit.
- This is a web app, not a Play Store APK.
